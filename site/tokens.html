Design tokens

Three tiers: a raw palette generated in OKLCH, semantic colors and role tokens that components use, and themes that decide which ramps feed them. Everything on this page is read from the live CSS, so switch theme, mode or density above and watch the values change.

Semantic colors

What a color is for. The contrast badge is measured against --os-color-surface in the current theme and mode. npm run check verifies 37 pairs for every theme × mode.

Role tokens

Spacing, shape, type and control sizes by role. Themes and data-density re-point these.

Type scale

Inter, self-hosted, with optical sizing. Headline sizes are fluid between 360px and 1280px viewports.
