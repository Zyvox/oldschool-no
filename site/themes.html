Themes and colour

Two separate choices. The theme decides the look — type, spacing, corners, which shade goes where. The accent decides the colour: one seed in tokens/palette.mjs grows every ramp, so re-branding a clone is a one-line change and a rebuild. Light and dark mode, density and width work with both themes.

<html lang="nb" data-theme="standard" data-mode="auto" data-density="standard">   <!-- retro is the default -->
<section class="os-panel" data-theme="retro"> … one retro box on a standard page … </section>

Try an accent

Pick any colour. The ramp keeps its hue and colourfulness and fixes the lightness of every step, so links, white button text and the frame keep their contrast. Then choose the frame: the accent itself, as in 2008, or a near-grey, so the colour is only on what you can click. The greys follow the frame. When you like it, paste the line into tokens/palette.mjs and run npm run build.

Recipes

Colour recipes

The retro theme with six palettes. Portal blue is the 2008 look, blue all over; the others keep the frame and header bands in a near-grey and use the colour for buttons, links and focus. Each is two lines in tokens/palette.mjs; nothing else changes.

Density

Independent of theme and colour. data-density re-points text size, row padding, box padding and control heights.

How it is built

  1. tokens/palette.mjs — the seeds: accent, an optional frame colour, neutral tint, optional link colour, visited and status colours. The build turns each into a ramp of fixed lightness steps.
  2. tokens/semantic.mjs — what each colour is for: link is accent.700 in light mode and accent.300 in dark, and so on.
  3. tokens/themes.mjs — the two themes, as overrides of type sizes, role tokens and semantic colours on top of that base.
  4. npm run build writes the CSS; npm test checks every text/background pair in both themes and modes against WCAG AA and fails the build if a seed breaks one.

The full guide — adding a third theme, changing what a theme overrides, adding a density — is in docs/theming.md.
